# data-cleaning-analysis-pandas
# Análise de Dados e Cancelamento de Clientes

## Visão Geral do Projeto
Este projeto apresenta uma análise de uma base de dados com mais de 50 mil registros, utilizando Python, Pandas e Plotly. O trabalho envolve a limpeza e preparação dos dados, além da criação de visualizações interativas para investigar padrões de cancelamento de clientes.

## Etapas do Projeto
- Limpeza e preparação da base de dados.
- Análise dos dados utilizando Pandas.
- Criação de visualizações interativas com Plotly.
- Investigação de padrões relacionados ao cancelamento de clientes.

## Tecnologias Utilizadas
- Python
- Pandas
- Plotly
- CSV
